# Data availability

## Public datasets

- snRNA-seq raw reads: NCBI Sequence Read Archive BioProject **PRJNA1545411**.
- Metabolomics: MetaboLights **MTBLS1478**.
- Proteomics: ProteomeXchange via iProX **PXD079762**.

## Data not redistributed

The following files are not included because of size or redistribution constraints:

- Raw FASTQ files.
- `possorted_genome_bam.bam` files.
- Cell Ranger count matrices.
- H5AD objects, including the 9,658-nucleus integrated object and external-reference objects.
- Intermediate RDS, pickle, NumPy and large TIFF files.

The repository includes code, source-data tables and vector/raster panel exports needed to audit the reported figures.
