# Analysis workflow

## 1. Inputs

The scripts expect the project data to be placed under a local `analysis_output/` directory and use the reference genome `GCF_003789085.1` (ASM378908v1).

Primary inputs:

- Cell Ranger filtered and raw matrices for `blank` and `treated` libraries.
- Cell Ranger `possorted_genome_bam.bam` files for velocity counting.
- Project-generated H5AD objects:
  - `adata_soupx.h5ad`
  - `adata_soupx_lognorm.h5ad`
  - `adata_hvg_processed.h5ad`
  - `adata_hemocyte_traj_geodesic.h5ad`
  - `step2/step2_integrated.h5ad`
  - `step3/step3_lyo_scores.h5ad`
- External reference programs:
  - eLife 80127 PH1 and PH2 programs.
  - Lymphoid-organ marker table.
- Orthology tables generated by BLASTP and SonicParanoid.

Large inputs are not included in this repository.

## 2. Base snRNA-seq processing

Run the project scripts in numeric order, starting with `01_load_qc.py` through the SoupX correction and downstream state annotation scripts (`20a`-`26`). The main operations are:

1. Load Cell Ranger matrices and per-nucleus QC statistics.
2. Estimate ambient RNA with SoupX from empty droplets (0 < UMI <= 10).
3. Apply `adjustCounts` and retain the corrected expression matrix.
4. Normalize to 10,000 counts per nucleus, apply log1p, and select highly variable genes.
5. Construct the Harmony-corrected graph/t-SNE representation.
6. Retain the delivered vendor state partition and annotate states using marker profiles and external references.
7. Test marker genes with Wilcoxon rank-sum tests and Benjamini-Hochberg correction.
8. Assign cell-cycle phases using 13 S-phase and 13 G2M genes.

Key scripts:

- `01_load_qc.py`
- `20a_soup_load.py` to `26_trajectory_soupx.py`
- `274_fig2a_all_states.py`
- `309_export_fig1_final_panels.py`

## 3. PH substates and trajectory

1. Subset PH nuclei and recluster with Harmony-adjusted principal components.
2. Resolve PH_s0 to PH_s3 and compute Wilcoxon markers.
3. Build the PH-GH diffusion pseudotime trajectory rooted at the ccnd2-high PH nucleus.
4. Project non-PH/GH nuclei onto the PH-GH manifold using 30 nearest neighbors.
5. Bin PH nuclei into 20 equal-count pseudotime bins per condition.

Key scripts:

- `248_step2_trajectory_projection.py`
- `249_step2_group_stats.py`
- `284_cross_tissue_prolif_ph.py`
- `288_ph_substate_composition.py`
- `289_ph_substate_marker_check.py`
- `307_export_fig2d_ph_tsne_final.py`

## 4. External progenitor programs and cell-cycle adjustment

1. Map eLife PH1/PH2 and lymphoid-organ programs to *L. vannamei* GeneIDs.
2. Calculate UCell-style within-nucleus rank scores.
3. Test top-marker overlaps with one-sided hypergeometric tests.
4. Fit the PH2 identity program against cell-cycle percentile in background nuclei.
5. Calculate cycle-adjusted residual z scores.
6. Use cycle-stratified permutation and bootstrap tests for Hs PH versus hemolymph PH and hepatopancreas R6.

Key scripts:

- `250_step3_lyo_program_mirror.py`
- `293_cross_organ_adjusted_progenitor.py`
- `295_supp14_lyo_marker_mirror.py`

## 5. Candidate niche ligand-receptor communication

1. Restrict candidate pairs to BLASTP- and SonicParanoid-supported orthogroups.
2. Calculate communication probability as source ligand mean multiplied by target receptor mean.
3. Test state-label permutation significance (1,000 permutations; 5,000 for key pairs).
4. Test group-specific source-target shifts with 500 label permutations.
5. Run 100 subsampling iterations with up to 40 source and 40 target nuclei.
6. Summarize ITGB1 expression across receiver groups.

Key scripts:

- `231_step1_communication.py`
- `232_step1_communication_validated.py`
- `247_step1_communication_sonicparanoid.py`
- `281_lr_sensitivity.py`
- `286_ligand_specificity.py`
- `268_supp7_receptor_group.py`

## 6. Supplementary tables S7-S18

Regenerate the source tables in three stages:

```powershell
python analysis_output/scripts/324a_build_S7_S12.py
python analysis_output/scripts/324b_build_S13_S18.py
python analysis_output/scripts/325_combine_validate_tables.py
python analysis_output/scripts/326_validate_S7_S18_workbook.py
```

`324a` creates sample metadata, nucleus metadata, QC, state markers, PH-substate markers and composition statistics. `324b` creates state-level differential expression, pseudotime bins, external-program scoring, candidate communication, orthology mapping and ITGB1 summaries. `324c_build_S19.py` is retained in the script archive but is not part of the current S7-S18 release.

Table rules:

- Existing Table S1-S6 are retained unchanged.
- New tables begin at Table S7.
- Table S19 is deferred and is not included in the current S7-S18 release.
- Missing measurements are left blank and explained in `notes`; no values are imputed.

## 7. Manuscript rebuild

`327_revise_manuscript_final.py` rebuilds the six-section revised DOCX from the supplied manuscript:

```powershell
python analysis_output/scripts/327_revise_manuscript_final.py
python analysis_output/scripts/328_final_validation.py
```

The script:

- Removes the separate 3.7 heading.
- Integrates former 3.7 material into sections 3.5 and 3.6.
- Aligns the six result headings and six figure captions.
- Rewrites the Figure 5 legend to include panel G.
- Rewrites the Figure 6 legend to match the current A-F panels.
- Updates references to Tables S7-S18.

## 8. Statistical interpretation

- Each snRNA-seq condition is one pooled library (n=1).
- Nucleus-level P values and FDR values are exploratory.
- BrdU/FACS experiments provide four independent biological batches.
- DPT, projected pseudotime and PH-to-GH ordering describe relative transcriptional order and do not establish lineage.
- Ligand-receptor results are candidate interactions, not functional validation.

## 9. Output checks

`328_final_validation.py` checks:

- Exact headers for Tables S7-S18.
- Unique nucleus IDs and sample counts in Table S8.
- Sum of retained nuclei in Tables S8, S9 and S12.
- PH substate counts and PH-only pseudotime bins.
- P-value ranges.
- Presence of every Table S7-S18 reference in the revised manuscript.
- Workbook headers, row counts and spot-checked values against the source JSON.
